# הכסף של הבית

אפליקציית תקציב משפחתית (PWA) בעברית, לכמה משפחות: מעלים פירוט אשראי/בנק (Excel, CSV, צילום או PDF),
מצלמים קבלות, רואים לאן הכסף הלך, מקבלים המלצות חיסכון, רשימת קניות משותפת, תקציבים, יעדים והתראות.

**כתובת:** https://elad-vibes.github.io/household-budget/ · הגרסה הקודמת (מקומית, בלי ענן): `/legacy/`

## פרטיות — בכנות
- כל משפחה רואה רק את הנתונים שלה. זה נאכף במסד הנתונים עצמו (Row Level Security), לא רק במסך,
  ונבדק בבדיקות אוטומטיות (משק בית א' לא יכול לקרוא או לכתוב למשק בית ב'; צופים לא יכולים לכתוב).
- **בעל פרויקט ה-Supabase (מי שהקים את המערכת) יכול טכנית לגשת למסד הנתונים** — דרך לוח הבקרה של
  Supabase או מפתח השירות. מסך "מנהל המערכת" באפליקציה מראה רק שימוש, מכסות ועלות, בלי תנועות וסכומים,
  אבל ההגבלה הזאת היא של האפליקציה, לא של בעל הפרויקט. מי שמצטרף סומך על מי שמפעיל את המערכת.
- צילומי קבלות נשמרים **רק בטלפון** עד שנקראו, ואז נמחקים (אלא אם סימנתם "לשמור לאחריות"). הם נשלחים
  לקריאה ל-Anthropic (Claude) ולא נשמרים בשרת שלנו; ה-batch נמחק אצל Anthropic אחרי שהתוצאות נשמרו.
- קבצי Excel/CSV נקראים במכשיר עצמו ולא נשלחים לשום מקום. צילום/PDF של פירוט נשלח ל-Claude לקריאה ולא נשמר.
- אימות דו-שלבי (אפליקציית אימות) חובה לבעלי משק בית ולמנהל המערכת; אפשר לחייב אותו לכל בני הבית.
- מחיקת חשבון ומחיקת משק בית מלאה — מתוך האפליקציה (הבית → חשבון).

## איך זה בנוי
Vite + TypeScript (בלי framework) · Supabase: Postgres + RLS, Auth (קוד במייל + TOTP), Edge Functions (Deno),
Realtime, pg_cron · Claude דרך Edge Functions בלבד (Haiku 4.5 ב-Message Batches לקבלות, Sonnet 5 לפירוטים ולניתוח) ·
GitHub Pages. פרטים: `PLAN.md` · החלטות: `DECISIONS.md` · אבטחה: `SECURITY.md` · הקמה: `SETUP.md` · ניהול: `ADMIN.md`.

## פיתוח
```bash
npm install                 # גם מתקין את ה-hooks של הסריקה (tools-git/)
npm run dev                 # http://localhost:5173/household-budget/
npm test                    # RLS (PGlite) + Edge Functions (Claude מדומה) + יחידה
npx playwright test         # E2E ברוחב אייפון (נתוני בדיקה בדויים על Supabase החי — מקומי בלבד)
npm run check:functions     # deno check לכל Edge Function
npm run scan                # סריקת בטיחות: סודות, מספרי כרטיס/ת"ז, נתונים אמיתיים
```
כללי העבודה בריפו: `AGENTS.md`.
